# Routing Logistik - Struktur Data

Program CLI berbasis C++ untuk simulasi logistik sederhana.  
Menggunakan Queue, Graph, dan Linked List untuk registrasi paket, dispatch antar kota, dan pelacakan resi.  
Project ini merupakan tugas mata kuliah Struktur Data semester 1.

## Cara Compile & Run
```bash
g++ main.cpp -o logistik.exe
.\logistik.exe
```

## Menu Simulasi
=== MENU SIMULASI LOGISTIK ===  
1. Registrasi Paket  
2. Dispatch Paket Jakarta -> Bandung  
3. Dispatch Paket Bandung -> Sumedang  
4. Lacak Resi  
0. Keluar  

## Contoh Output
Histori paket RESI001:  
-> Jakarta  
-> Bandung  
-> Sumedang
